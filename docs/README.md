# Documentation 📚

Pasta destinada ao armazenamento dos documentos e materiais de planejamento, desenvolvimento e apresentação do projeto **PassGuardian**.

## 📁 Estrutura

```text
docs/
├── diagrams/
├── presentations/
├── ui-ux/
└── uml/
```

## 📂 Organização

| Pasta | Conteúdo |
|---|---|
| `diagrams/` | Diagramas de funcionamento, fluxos e processos do sistema. |
| `presentations/` | Apresentações e materiais utilizados para demonstrar o projeto. |
| `ui-ux/` | Documentos, esboços e referências relacionados à interface e experiência do usuário. |
| `uml/` | Diagramas UML para representar a estrutura e o comportamento do sistema. |

## 🎯 Objetivo

Manter os documentos do projeto organizados e separados do código-fonte e dos recursos visuais.

Essa organização facilita a consulta, manutenção e evolução do PassGuardian.
